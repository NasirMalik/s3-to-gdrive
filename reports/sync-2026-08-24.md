## Blocker

```

→ Your session has expired or credentials have changed.
  Please reauthenticate using 'aws login'.
```

The AWS MCP server drives the AWS CLI on the local machine and inherits its SSO session, so
this reflects local credential state — the SSO session is expired.

Per `SKILL.md` Phase 1, no attempt was made to run `aws sso login`, a browser login, or any
other route to credentials: refreshing SSO needs interactive device-authorization approval
that an unattended run cannot give. The run went straight to Phase 7 in BLOCKED mode.

**Fix:**

```bash

# then re-trigger the sync (or wait for next week's scheduled run)
```
