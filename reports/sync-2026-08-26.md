## Script fix (not a guardrail change)

`scripts/analyze_configs.py` had a pre-existing bug: `country_code` is a YAML list
(`country_code: [gr]`) but was used directly as a dict key and as a JSON object key,
which raised `TypeError: unhashable type: 'list'`. Fixed by normalizing it to a
comma-joined string at parse time (`analyze_config()`). This is a data-normalization fix,
not a change to `--allow-shrink`, `--shrink-threshold`, or the Confluence splice logic —
none of those guardrails were touched or bypassed.
